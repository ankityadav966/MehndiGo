# Notification Bell Navigation UX

## 1. Dedicated Notifications Page Requirement
- Clicking the Notification Bell icon (top bar, header, navbar, or dashboard summary card) MUST directly navigate the user or artist to a dedicated, full-screen Notifications Page (`/notifications` on Web, `Notifications` screen on Mobile).
- The Notifications Page must feature category filters (*All*, *Unread*, *Bookings*, *System*), *Mark All as Read* controls, relative timestamps, and unread badges.
