# Rule: Hide Unimplemented UI Features

When modifying or adding to screens in the MehndiGo mobile app (especially the Artist Profile and Service Catalog screens), adhere to the following constraint:

1. **Share Buttons**: Do not add or enable the "Share" functionality (e.g. share-social-outline icon buttons in headers) if it's not fully tested or implemented. Keep it removed or commented out.
2. **Live Availability/Upcoming Slots**: Do not display the "Section 5: Live Availability Schedule Preview" or similar upcoming slot availability blocks. Ensure these remain commented out until the backend and frontend features are fully supported.
