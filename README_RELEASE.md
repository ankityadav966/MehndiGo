## 3. Play Store Data Safety Questionnaire

- **Data Collection**:
  - *Location*: Approximate location (for calculating proximity listings) and precise location (for booking directions navigation).
  - *Personal Info*: Name, email address, phone number.
  - *Financial Info*: Purchase history, payments ledger logs (for wallet/booking history).
  - *Messages*: In-app chat texts.
- **Data Security**:
  - All data is encrypted in transit using standard HTTPS protocol.
  - Customers can request user account deletion inside settings console.
